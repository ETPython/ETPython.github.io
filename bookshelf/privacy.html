プライバシーポリシー

本棚ノート

「本棚ノート」(以下「本アプリ」)における、利用者の情報の取り扱いについて定めます。

1. 本アプリが端末内で扱う情報

  • 登録した本の情報(書名・著者・出版社・ISBN・ジャンル・置き場所・読書状態・評価・内容のメモ・感想)は、端末の中にだけ保存します。本アプリの運営者のサーバーには送信しません。
  • カメラは、本のバーコード(ISBN)の読み取りと、本棚の撮影に使います。バーコードの映像は読み取りにだけ使い、保存しません。
  • 本棚の写真(撮影したもの、または写真ライブラリから選んだもの)は、背表紙の文字を端末の中で読み取るために使います。写真は外部に送信しません。読み取った本を登録すると、写真はあとで見返せるよう端末の中に保存します。本を削除すると写真も削除します。

本アプリにはアカウントやログインの機能はなく、氏名・メールアドレスなどの個人情報を取得しません。

2. 書誌情報の検索

本の書名・著者・出版社・分類を調べるため、国立国会図書館が提供する「国立国会図書館サーチ」の API に、読み取った ISBN、または利用者が確認した書名・著者名を送信します。送信するのは本の情報だけで、利用者を特定する情報は含みません。

  • 国立国会図書館サーチ API について(書誌データは CC BY 4.0 で提供されています)

3. 広告について

本アプリは、Google LLC の広告配信サービス「Google AdMob」を利用して、画面下部にバナー広告を表示します。広告の配信のため、Google が端末の識別子、おおよその位置情報、広告の表示・操作の状況などの情報を取得する場合があります。本アプリは、他社のアプリやウェブサイトをまたいだ追跡(トラッキング)の許可を求めていません。

Google による情報の取り扱いは、次のページをご覧ください。

  • Google プライバシーポリシー
  • 広告(Google のポリシーと規約)

4. 第三者への提供

本アプリの運営者は、上記の書誌情報の検索と広告配信を除き、利用者の情報を第三者に提供しません。
