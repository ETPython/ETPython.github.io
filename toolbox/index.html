Tool Box サポート

定規・分度器・水平器(iPhone)

Tool Box は、定規・分度器・水平器をひとつにまとめたアプリです。クレジットカードや硬貨で定規を、180°回すだけで水平器を校正でき、補正後の誤差も表示します。尺・寸や寸勾配にも対応しています。

よくある質問

定規の長さが実物と合いません。
定規タブの「校正」から、クレジットカード(長辺 85.6mm)や硬貨を画面に当て、線を端に合わせて保存してください。カードを使うのが最も正確です。

水平器が、平らな場所でも 0° になりません。
端末やケースによって少しずれがあります。水平器タブの「校正」で、端末を置いて記録したあと、180°回して同じ場所に置き直してください。自動で補正値を計算します。ケースを付け外しする場合は、設定の「水平器のプロファイル」で補正値を分けて保存できます。

カメラ分度器が使えません。
iPhone の「設定」→「Tool Box 計測器」で、カメラを許可してください。

計測の精度はどのくらいですか。
スマートフォンのセンサーや画面を使った簡易的な計測です。校正後の推定誤差を画面に表示していますが、端末によって差があります。精度が必要な用途では専用の計測器をお使いください。
