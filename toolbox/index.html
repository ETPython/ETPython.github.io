Tool Box サポート

定規・分度器・水平器・拡大鏡・スロー撮影(iPhone)

Tool Box は、定規・分度器・水平器・拡大鏡・スロー撮影をひとつにまとめたアプリです。クレジットカードや硬貨で定規を、180°回すだけで水平器を校正でき、補正後の誤差も表示します。尺・寸や寸勾配にも対応しています。

よくある質問

定規の長さが実物と合いません。
定規タブの「校正」から、クレジットカード(長辺 85.6mm)や硬貨を画面に当て、線を端に合わせて保存してください。カードを使うのが最も正確です。

水平器が、平らな場所でも 0° になりません。
端末やケースによって少しずれがあります。水平器タブの「校正」で、端末を置いて記録したあと、180°回して同じ場所に置き直してください。自動で補正値を計算します。ケースを付け外しする場合は、設定の「水平器のプロファイル」で補正値を分けて保存できます。

拡大鏡で寸法を測るには?
測りたい物のすぐ横に、クレジットカード(長辺 85.6mm)か硬貨を置いて、真上から写します。「静止」で映像を止め、赤い印を基準物の両端に、黄色い線を測りたい所に合わせると長さが表示されます。ピンチで拡大してから合わせると、誤差が小さくなります。基準物と測る物が同じ高さ(同じ平面)にないと、正しく測れません。

スロー撮影で時間や速さを測るには?
端末を固定し、明るい場所で撮影します(最大 240 コマ/秒、10 秒まで)。再生画面でコマ送りし、「A に設定」「B に設定」で 2 つのコマを決めると、間の時間を表示します。速さを測るときは、動く物と同じ面にクレジットカードなどを置いて写し、「速さ」をオンにして、赤い印を基準物の両端に、A・B の印を各コマでの物の位置に合わせます。

撮った動画はどこに保存されますか。
アプリの中にだけ一時的に置き、画面を離れると消えます。残したいときは、再生画面の右上の保存ボタンで写真アプリに保存してください。

カメラを使うツールが使えません。
iPhone の「設定」→「Tool Box 計測器」で、カメラを許可してください。動画を写真アプリに保存できないときは、同じ画面で「写真」を「追加のみ」以上にしてください。

計測の精度はどのくらいですか。
スマートフォンのセンサーや画面を使った簡易的な計測です。校正後の推定誤差を画面に表示していますが、端末によって差があります。精度が必要な用途では専用の計測器をお使いください。
